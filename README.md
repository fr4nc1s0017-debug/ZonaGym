# ZonaGym

# Sistema Web para Control Básico de Gimnasio

## Descripción

Sistema web desarrollado para la gestión administrativa de un gimnasio, permitiendo el control de clientes, membresías, pagos, asistencia y rutinas de entrenamiento.



## Objetivo

Digitalizar los procesos del gimnasio para mejorar la organización, control financiero y seguimiento de clientes.



## Tecnologías utilizadas

* PHP 8.x
* Laravel 11
* MySQL
* HTML, CSS, JavaScript
* Tailwind CSS



## Metodología de trabajo: SCRUM

El equipo implementa Scrum para el desarrollo del proyecto, organizando el trabajo en sprints de 2 semanas.

### Eventos Scrum

* *Sprint Planning:* Definición de tareas a realizar
* *Daily Scrum:* Seguimiento diario del progreso
* *Sprint Review:* Evaluación de resultados
* *Sprint Retrospective:* Mejora continua del equipo
